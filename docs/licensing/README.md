# Licensing notes

- Application source-code license: not yet selected for this private Alpha repository.
- The current Alpha Chat 2.0 runtime does not bundle a local inference model.
- AI generation is provided through the configured remote free-only Gemini backend.
- Third-party runtime and library dependencies must retain any license/NOTICE metadata required by their upstream licenses.
- If a local model is added in the future, its exact artifact, revision, source and license must be recorded before distribution.
